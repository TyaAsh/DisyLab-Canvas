# DisyLab v1.0.4 版本说明

发布日期：2026-08-20

v1.0.4 将工作流与视频创作正式纳入 DisyLab 的画布体系，同时完成了一轮面向可读性、交互一致性和多平台部署的体验升级。

## 工作流

- 新增工作流模板弹窗、分类、搜索和模板预览。
- 支持将工作流直接加入当前画布，复用结构化节点流程。
- 使用 GSAP 优化工作流弹窗的进入、退出与状态切换动效。
- 灵感库与工作流弹窗支持点击遮罩或按 Esc 关闭。

## 视频生成

- 新增视频节点与视频 Agent 方案确认流程。
- 支持文生视频、图生视频、首尾帧、图片参考和全能参考模式。
- 按模型能力动态限制清晰度、时长、比例、音频和参考素材。
- 项目风格预设可参与支持参考图的视频生成模式。
- APIYI Seedance、Veo、Wan 与 OpenAI 兼容接口可通过统一连接配置调用。

## 视频编辑与预览

- 新增可拖动的紧凑剪辑台，支持 Esc 关闭且不会覆盖模态弹窗。
- 新增视频九宫格裁剪，裁剪确认界面与节点画布保持一致。
- 新增当前帧、首帧和尾帧截取菜单，并可将结果沉淀为画布素材。
- 新增全屏预览、下载、音量、循环和播放进度控制。
- 修复剪辑后视频在全屏预览中当前时间与总时长不一致的问题。
- 修复节点工具条在画布滚动或缩放时与视频节点脱离的问题。

## 视觉与交互

- 节点卡片、节点编辑器、悬浮工具条、菜单与弹窗统一升级为 iOS 26 风格高不透明度磨砂玻璃材质。
- 提升视频参数和图像参数面板的对比度与阅读性，避免背景内容穿透干扰。
- 优化主题色按钮、图标、悬停和选中状态，减少突兀的高亮蓝色与侧边高亮。
- 统一可点击遮罩弹窗的 Esc 关闭行为，并修正剪辑台、遮罩和弹窗的层级关系。
- 修复视频模式切换时参数窗口跳动以及部分弹窗横向空白的问题。

## 部署与工程

- 版本号统一更新为 v1.0.4。
- Cloudflare Pages、Netlify 与 Vercel 新增视频任务、状态轮询和媒体回传 relay。
- GitHub Pages 官网同步 v1.0.4 工作流、视频能力和三语路线图。
- README 提供简体中文、繁體中文与 English 版本。

## 后续计划

- 下个版本将推出 **3D 预演台** 与 **Skill 集成**。
- 前后端分离与桌面端正在开发中。
- 更多语言以及深色／浅色模式将逐步开放。

## 升级建议

- 推荐使用 Node.js 22.12 或更新版本。
- 升级后请重新执行 `npm install`，再运行 `npm run typecheck` 与 `npm run build`。
- API Key 继续独立保存在浏览器本地，不会写入导出的 `.disy` 项目包。
