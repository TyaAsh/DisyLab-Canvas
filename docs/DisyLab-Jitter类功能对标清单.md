# DisyLab Motion：Jitter 类功能对标清单

> 版本：v1.0  
> 日期：2026-08-21  
> 用途：产品范围、排期和验收的唯一功能矩阵  
> 原则：对标能力与工作流，不复制 Jitter 品牌、素材、代码或私有实现

## 1. 发布级别

- **MVP**：可以完成真实作品的最小闭环。
- **Core**：Jitter 类工具的核心工作流完整，目标日期 2027-01-29。
- **Full**：高级导出、模板规模和稳定性达到正式产品候选，目标日期 2027-03-26。
- **Later**：需要账号、云端基础设施或高成本渲染后端，另立项目。

## 2. 设计与素材

| 能力 | 级别 | 验收定义 |
|---|---|---|
| 无限场景画布 | Core | 同一文件并排组织多个场景并独立设置比例 |
| 文字、图片、SVG、视频、音频 | Core | 可导入、编辑、替换、持久化和导出 |
| 基础形状与钢笔路径 | Core | 可创建矩形/圆形/路径并编辑节点 |
| 图层、编组、锁定、显隐、排序 | MVP | 操作可撤销且刷新恢复 |
| 对齐、分布和智能吸附 | Core | 多选对象可快捷对齐并显示吸附参考线 |
| 圆角、填充、描边、渐变 | Core | 属性可动画化或明确标记静态 |
| 模糊和背景模糊 | Core | 预览与视频导出一致 |
| 混合模式 | Core | 支持常用模式并进行兼容检查 |

## 3. 时间轴与动画

| 能力 | 级别 | 验收定义 |
|---|---|---|
| 播放头、标尺、缩放、吸附 | MVP | 30/60fps 下定位与显示一致 |
| 关键帧创建、移动、复制、删除 | MVP | 支持多选、撤销和键盘操作 |
| 图层 in/out 与裁切 | MVP | 控制可见区间并反映到导出 |
| 属性轨道 | MVP | 位置、缩放、旋转、透明度 |
| 高级属性轨道 | Core | 模糊、颜色、圆角、路径等按能力支持 |

| 自定义缓动 | Core | cubic-bezier 编辑、保存和复用 |

| 路径运动 | Core | Bezier 路径、朝向路径和进度动画 |
| SVG Morph | Core | 兼容路径间平滑变形并给出限制提示 |
| 动画复制/粘贴 | Core | 跨图层、场景和文件复用 |
| 循环与点击动画 | Full | 场景循环、片段循环和交互触发模型 |

## 10. 数量与质量门槛

Jitter 类核心版发布前至少达到：

- 40 个可编辑动画预设，其中不少于 20 个文字/错峰预设。
- 20 个官方模板；完整版候选达到 50 个以上。
- 5 类黄金工程：Logo、文字、海报、产品轮播、视频混排。
- 20 图层/10 秒/1080p 工程可稳定编辑和导出。
- WebM、MP4、GIF、Lottie 四类导出均有明确支持矩阵。
- 模板创建、预览、套用、替换和导出形成完整闭环。

## 11. 范围解释

“类似 Jitter 的都要有”在本项目中定义为：完整覆盖独立创作者进行动效设计、动画编辑、模板复用和成品导出的主工作流。涉及云端团队协作、SSO、在线评论、企业管理或重型服务端渲染的能力会保留接口，但必须另立基础设施项目，不能与本地优先动效编辑器混为同一排期。
