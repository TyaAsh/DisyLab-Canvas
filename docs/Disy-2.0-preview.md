# DisyLab 2.0 前瞻

版本：`2.0.0-preview.1`

- **Skill 与 Disy 对话**：选择引导型 Skill 后逐题补齐信息；填写自定义答案时仍能看到现有选项。空画布和 Agent 共用 Skill 入口，画布节点只列出可直接应用的 Skill。创建与管理 Skill 时可选择使用方式。
- **技能库与画布**：分类管理保持固定高度，列表在面板内部滚动。「我的 Skill」使用菜单内说明两种用法。图层支持分组、重命名、复制、拖动排序和固定在左侧。画布浮动控件使用同一套毛玻璃材质。
- **文件工具箱**：统一图片、视频和 PDF 工具的拖放区配色。新增图片与视频去水印，可框选位置固定的角标、预览并下载。视频处理保留原声，图片处理保留原图尺寸。
- **从链接导入**：两种去水印工具都可读取可公开访问的媒体直链，或尝试读取小红书、抖音公开分享页。识别到明确的固定水印时会生成修补结果；识别不到时可手动框选。平台没有返回媒体时，请改用本地文件。普通 YouTube 分享页不能直接导入。

简易视频剪辑台、剧本工厂和桌面 MCP 接入留待后续版本。
