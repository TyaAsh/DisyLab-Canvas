# IP 换装短片：视频拆解与工业化复现规范

## 结论

这类内容应采用“引导式 Skill 负责定义母版与审核口径，串行工作流负责生产”的组合。它不是依靠单条提示词完成的换装特效，而是一套角色一致性、舞台一致性、造型资产、动作遮挡、节拍剪辑和声音设计共同组成的短视频格式。

在 DisyLab 中，用户从工作流模板库启动“IP 换装秀 · 连续角色短片”。工作流必须按连线顺序执行；每一步完成后停留，用户审核通过才允许执行下一步。任何身份、服装、舞台或首尾帧偏差都应回退到产生偏差的上游节点，不允许用转场掩盖。

## 源视频客观参数

- 时长：18.583 秒
- 画面：834 × 1112，约 3:4 竖版
- 帧率：24 fps
- 编码：H.264，约 1.03 Mbps
- 音频：AAC，48 kHz，双声道
- 主体：橙白色毛绒牛形 IP，玻璃纽扣眼、白色口鼻、小角、小耳朵、短四肢
- 场景：固定红白马戏舞台、圆形转台、木地板、暖色串灯、窗侧柔光
- 造型数量：约 8 套，涵盖球衣、衬衫、街头、赛车、秋冬、机车、针织和围巾大衣

## 视觉语言

### 构图

- 主体始终居中，角色占画面高度约 45%–70%。
- 舞台中心和角色脚底是固定空间锚点；即使换景别，也不破坏视觉轴。
- 以正面全身为主，穿插背面、三分之二侧面和胸像近景。
- 背景信息稳定，靠造型和动作变化提供新鲜度。

### 光线与色彩

- 暖钨丝灯与柔和窗光共同形成奶油质感高光。
- 红、橙、象牙白构成底色，服装可引入蓝、黑、棋盘格等对比色。
- 对比度中等，黑位不死，毛绒高光不塑料化。
- 景深较浅但角色轮廓完整，背景灯串形成稳定散景。

### 材质

- 角色：短绒毛、轻微不均匀纤维方向、柔软受压边缘。
- 眼睛：深色玻璃或高光塑料纽扣，但不能改变形状和间距。
- 服装：必须像缩小后的真实成衣，能看见针织纹、缝线、纽扣、皮革折痕、金属配件和衣物与毛绒的接触压痕。
- 舞台：哑光织物帘幕、刷漆木、磨损圆台，不使用过度光滑的通用 3D 塑料材质。

## 时间与镜头结构

1. 0.0–1.8 秒：球衣造型，固定正面建立角色身份。
2. 1.8–5.7 秒：条纹衬衫，正面转向侧背并回看，利用转身建立换装语法。
3. 5.7–7.2 秒：黑红街头造型，正面短动作，完成第一次明显风格跃迁。
4. 7.2–8.8 秒：赛车服与墨镜，姿态更外放，节奏提速。
5. 8.8–12.6 秒：前景遮挡切入秋冬造型并出现秋千，改变运动方式但不改变舞台世界。
6. 12.6–13.6 秒：机车皮衣近景，依靠镜头推进提高能量。
7. 13.6–14.3 秒：针织造型作为极短过桥。
8. 14.3–17.3 秒：红围巾大衣英雄造型，动作减慢，承担收束。
9. 17.3–18.58 秒：角色退场或虚化，品牌标识稳定出现。

实际生成时不要求一次生成 18 秒。每套造型以 1.5–2.5 秒短镜生成，分别锁定首尾帧，再通过遮挡匹配和音乐重拍剪辑。长镜会放大身份漂移、衣物融化和舞台闪烁风险。

## 转场机制

- 转身匹配：上一造型转至侧背，在相同身体角度切换下一造型。
- 前景遮挡：红布、角色头部、道具或衣摆完整遮住主体后切换。
- 构图匹配：角色眼睛、头顶、脚底和舞台圆心在切前切后保持同坐标。
- 动作接力：上一镜动作尾速率与下一镜起速率一致。
- 声音桥：衣物摩擦、脚步、摆动和冲击音跨越画面切点，降低硬切感。

禁止使用无来源的闪白、故障、旋转、液化和随机粒子转场。这些效果不能修复角色或服装漂移。

## 用户引导步骤

1. 上传 IP 标准参考：优先正面全身、侧面、背面和面部近景。
2. 上传服装与配饰参考：每套服装单独准备，避免一张图出现多个不明确目标。
3. 填写发布平台、目标时长、画幅、造型数量、音乐和品牌尾标。
4. 生成并审核形式圣经与逐拍表。
5. 生成并审核角色与舞台母版；此处锁定身份和材质。
6. 生成并审核多造型定妆板；此处只审服装，不做视频。
7. 生成 A/B 两段首尾关键帧；逐个检查遮挡点和构图匹配。
8. 串行生成每个短镜；上一镜通过后才执行下一镜。
9. 按音乐重拍剪辑，添加服装、脚步、摆动和冲击声音。
10. 运行连续性质检，交付 9:16 主版、3:4 安全裁切版和无音乐素材版。

## 硬性验收标准

- 角色眼睛位置、角、耳朵、口鼻轮廓、毛色和头身比不漂移。
- 舞台圆心、角色脚底高度、背景条纹和主光方向不跳动。
- 服装边缘与毛绒接触自然，不融进身体，不随机增减配饰。
- 遮挡帧必须完整覆盖需要隐藏的区域。
- 换装切点与音乐重拍误差不超过 2 帧。
- 每个镜头只有一个主要动作，动作完成后至少保留 8–12 帧稳定画面。
- 品牌尾帧稳定不少于 18 帧，无错误文字、额外 Logo 或水印。
