# DisyLab v1.0.5 版本说明

发布日期：2026-08-21

v1.0.5 扩展了可复用创作能力与本地文件处理，并集中修复个人中心、全局弹窗层级和画布导航等交互问题。

## 新功能

- 图像节点和文本节点支持通过 `/` 打开 Skill 菜单。
- Skill 支持直接执行、配置后执行、自定义 Manifest 导入、文件夹批量导入、查看与删除。
- 新增漫画分镜工作流，覆盖内容拆解、版式选择、构图确认和素材生成。
- 新增文件工具箱入口，提供图片压缩、视频压缩、PDF 压缩与 PDF 合并。
- 个人中心完善搜索、宫格/列表切换、批量选择、项目导入导出和独立 API 配置入口。

## 体验与稳定性

- 建立统一的全局层级规则，隔离画布工具、个人中心、全屏遮罩、确认弹窗与关键进度提示。
- 修复遮罩弹窗打开后顶部工具、侧边栏、小地图和输出历史仍显示在遮罩上方的问题。
- 修复个人中心的新建项目、API 配置、导入导出和删除确认弹窗被个人中心遮挡的问题。
- 进入个人中心时自动关闭画布专属浮层，避免帮助、工具箱、节点搜索、Agent 和 Skill 配置残留。
- 修复小地图无法拖拽导航的问题，并保留缩放与适应画布能力。
- 图像 Skill 与文本 Skill 面板改用和图像参数一致的高可读性深色背景。
- 优化项目入口逻辑，画布中的项目管理统一返回全屏个人中心。

## 开发与发布

- 应用、导出包标识、版权标记、README 与项目官网统一更新至 v1.0.5。
- GitHub Pages 官网同步 v1.0.5 功能与新版路线图。
- 生产版本继续部署至 Cloudflare Pages。

## 后续路线

- 下一小版本：多语言以及深色 / 浅色模式切换。
- 大版本：D-Motion，面向轻量化动效制作。
- 大版本：D-Board，支持手绘、头脑风暴、流程图、表格，以及 PDF 等多种格式导出。
- 前后端分离暂不推进。
- 桌面端将在大版本之后同步推出。
- 音频生成将在后续版本逐步加入。
