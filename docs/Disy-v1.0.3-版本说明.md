# DisyLab v1.0.3 版本说明

发布日期：2026-08-13

## 本次更新

- 项目对外版本统一更新为 `v1.0.3`：应用元数据、构建版权标记、离线数据标记、站点页、授权说明与文档均使用同一版本号。
- **图像悬浮工具条**：宫格切分、自由扩图、免费本地抠图、评论修改与打光集中于图片上方；下载和加入资产库始终位于工具条末尾，放大预览也保留这两个操作。
- **自由宫格切分**：提供 4 / 9 / 16 / 25 宫格预设和自定义行列；网格按原图比例绘制，分割线可自由拖动。
- **自由区域扩图**：可选原比例、1:1、4:3、16:9、3:4、9:16 等比例，也可填写精确尺寸；四边可独立向外延展并保留可编辑的延展提示词。确认后自动创建下游任务、连线并立即开始生成。
- **本地抠图**：采用本地模型执行背景移除，不消耗 API 积分；载入、执行与失败状态持续可见，输出会自动进入节点、生成历史和资产流程。
- **评论修改**：在图上落点添加最多 5 条编号评论；每条评论可单独填写修改要求，确认后生成下游编辑任务，保留原图、评论与任务历史。
- **打光**：引入 Three.js 球面光位预览。主光源可直接拖动，亮度、色温、主光方向与轮廓光可调；预览采用按需渲染与资源释放，避免编辑画布卡顿。
- **提示库**：统一为可编辑的“灵感案例”；行业素材已合并其中，只保留“全部 / 金融科技 / 视觉案例”分类，不再展示风格筛选。支持搜索、24 条分页、懒加载、图片压缩、拖入画布与写入提示词节点；用户可本地移除不需要的案例，自建并删除个人分类。
- **内容与性能治理**：提示库图片采用压缩 WebP，行业素材与参考图做 URL、像素哈希与缺图校验；删除露骨、性暗示及不符合高级创作定位的案例，并在采集脚本中永久排除。

## 使用说明

1. 选中图像节点，在图像上方悬浮工具条选择需要的编辑功能。
2. 宫格、扩图、抠图、评论修改和打光的结果都会通过下游图像节点保留在画布中。
3. 从侧边栏打开“提示库”，可将案例图拖至画布作为参考，或直接将 Prompt 写入提示词节点。
4. 本地数据、资产和生成历史会随使用量增长；界面以分页、懒加载和可见项渲染控制内存占用。

## 已知限制

- 本地抠图首次使用需下载模型资源，受网络与浏览器 WebAssembly 支持影响；加载状态会持续显示。
- 评论修改是否支持像素级蒙版取决于所选生图服务；支持图像编辑蒙版的模型效果最佳，其他服务会采用参考图降级策略。
- 打光面板生成的是用于下游生图的灯光提示词，并非直接修改原图片像素。
